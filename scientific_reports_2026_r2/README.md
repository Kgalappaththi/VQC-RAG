# Scientific Reports – second-round revision

Selected source code and configuration files from the archived reproducibility release, version 1.0.0: https://doi.org/10.5281/zenodo.24132662.

This is a code-only subset, not a standalone runnable reproduction package. Obtain the full archive from Zenodo for data, checkpoints, results, original directory layout and execution instructions. Run the full archive in a separate working directory. Historical scripts and absolute paths may require adaptation. No experimental source code has been modified.
