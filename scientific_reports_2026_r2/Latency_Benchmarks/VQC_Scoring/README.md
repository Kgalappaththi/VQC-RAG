# VQC scoring benchmark

Run from the repository root: `python Latency_Benchmarks/VQC_Scoring/benchmark_latency.py --repo VQC_SciFact_Reproducibility_v1 --repeats 5 --out new_vqc_latency`. Cached six-component features, 20 candidates per query; excludes retrieval and preprocessing. The linear scorer is not a trained MLP. Archived statistical comparisons are exploratory.
